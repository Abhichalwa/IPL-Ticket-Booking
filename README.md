
# 🏏 IPL 2026 Ticket Booking Website

## About the Project
This project is a basic IPL 2026 Ticket Booking Website created using HTML. It provides a simple interface where users can explore match schedules, view ticket prices, and enter their booking details.

## Features
- Navigation bar with different sections
- IPL 2026 welcome banner
- About IPL and popular teams
- Match schedule with ticket prices
- Team filter dropdown
- Ticket booking form
- Booking summary section
- My Ticket Bookings table
- Stadium booking guidelines
- Footer section

## Technologies Used
- HTML5

## Website Sections
1. Home
2. About IPL 2026
3. Match Schedule
4. Book Your Tickets
5. My Ticket Bookings
6. Booking Guidelines

## How to Run
1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open the `index.html` file.
4. Run it using Live Server or open it directly in a browser.

## Objective
To understand and implement semantic HTML elements by developing the basic structure of an IPL ticket booking website.
